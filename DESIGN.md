# Store design

Preserve the established cream, forest green and pumpkin orange palette. Product photography is actual 3D mesh rendering. Use airy spacing, serif Chinese headings, quiet sans-serif utility text and warm editorial composition. Homepage hero leads to a five-product collection; categories and search remain directly above products. Product details and shopping bag use native dialogs with Escape and visible close controls. Checkout clearly states free collection and exposes individual ZIP downloads.

Tokens: paper #f7f5ee; ink #233c32; muted #59685e; orange #bd4f26; rule #d6dcd1. Body line-height 1.7. Display uses Noto Serif TC with serif fallback. Responsive product grid: four columns desktop, two tablet/mobile. Native dialog focus, reduced-motion preference and visible keyboard focus are retained.

Construction variants stay inside each product detail. A native radio group chooses 一體成型 or 分件組裝; a native select then chooses color/print options. Preview, print time, notes, guide, cart identity and ZIP link all derive from the selected variant. Categories describe the design rather than manufacturing method. Mono variants use actual mono mesh renders and explicitly require hand painting to reproduce the color concept.

The homepage hero uses a bronze Halloween arch around the real ghost render, with restrained orange lighting, geometric bat and pumpkin ornaments. Keep the rest of the established store design. Original-color one-piece variants use actual color-partitioned mesh renders and expose filament requirements, including seven slots for Kitty. Kitty stays black-haired with white ears; never use the old white hood.

Moon Count uses the existing holiday category and the homepage Halloween doorway. Its wings, collar, burgundy vest and gold crescent are modeled geometry; previews come from these actual meshes.

The Halloween doorway uses concentric bronze archivolts, carved pilasters, a crescent crest, paired candle lanterns and restrained low mist. The Count remains an actual model render. Decoration is inline geometric SVG with no pointer interaction; the arch still links to the collection.
