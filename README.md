# 小陳晉製造所

數位公仔模型商店，依造型整理為 5 個商品：月夜伯爵、幽靈、南瓜、粽子、Hello Kitty 小陳晉。

網站：https://zyyuy0u.github.io/3d-xiao-chenjin/

每個商品內可選 **一體成型** 或 **分件組裝**。購物袋與下載會保留所選形式及配色，避免下載錯誤版本。

- 一體成型：每款皆可選原配色或單色。幽靈／南瓜原配色為四色，貓耳款為七色（需七個供料槽位）。單色版本需自行上色。
- 經典粽子的一體成型另有既有四色版。
- 分件組裝：保留原配色；貓耳另提供需手工補色的省時組裝方案。
- Hello Kitty 寬身新版：身體比頭更寬，貓耳根部修圓融入黑髮；整體約 100 mm。

目前免費領取，尚未啟用付款服務。價格與收款平台仍待提供；GitHub Pages 上的公開下載不具付費存取控制。

範例為 Bambu Lab X1 Carbon／0.4 mm／PLA。請依設備重新切片；模型尚未實體試印。

## 維護與檢查

`products.json` 以造型定義商品，每個商品的 `variants` 保存形式、配色、下載包與時間估計。`models.json` 保存 28 份 3MF 的 SHA-256。`assets/` 只有實際模型渲染，沒有原始人像照片。

```sh
python3 -m http.server 8765
python3 tools/validate_site.py
```

Hello Kitty 小陳晉保留加寬身體與融合貓耳，右側加上立體紅色蝴蝶結；頭髮、貓耳與蝴蝶結仍為同一個組裝件。

月夜伯爵小陳晉提供三件原配色組裝、五色一體成型與單色一體成型；蝠翼厚度 5 mm，實際模型與切片已驗證，尚未實體試印。

月夜伯爵精修版加寬、加厚禮服，改為弧形蝠翼，新增立體衣襟滾邊、披風摺線與金扣。各製作形式及預覽均同步更新。
