# 小陳晉製造所

數位公仔模型下載商店：商品分類、搜尋、商品詳情、購物袋與 ZIP 下載。

網站：https://zyyuy0u.github.io/3d-xiao-chenjin/

## 商品

- 節日限定：南瓜裡的小陳晉（三件組裝）。
- 分件組裝：粽葉裡的小陳晉（原色三件組裝）。
- 一體成形：經典粽子四色、經典粽子單色。

共 4 款商品、9 份 3MF。「單色三件組裝」與「八件分色組裝」已下架。

## 領取流程

商品目前為免費下載。加入購物袋、確認免費領取後，可分別下載整套 ZIP。購物袋與最近一次領取紀錄儲存在目前瀏覽器，不收集姓名或付款資料。

實際收款尚未啟用；付費版需要商品售價、收款平台與伺服器端付款驗證。GitHub Pages 目前提供公開靜態檔案，不能作為付費檔案的存取保護。

`products.json` 管理分類與商品資料；`store.js` 實作篩選、購物袋與免費領取。`downloads/` 為完整模型包，`assets/` 為實際模型渲染，`docs/` 為列印說明。

## 本機預覽與驗證

```sh
python3 -m http.server 8765
python3 tools/validate_site.py
```

範例設定：Bambu Lab X1 Carbon／0.4 mm／PLA。下載後請在 Bambu Studio 以專案開啟，依設備及材料重新切片；模型尚未實體試印。

網站不含原始人像照片或真人模型。
